# Opening a pr

Read [the runtime contract](../references/claude-runtime.md) first.

Inspect repository instructions, template, branch/base, commits, and the final diff. Run appropriate checks and inspect for unintended files or secrets. Push/create only within the user-authorized development scope. Write a title and body about the concrete problem, resulting behavior, validation, and material limits. Use a body file for multiline CLI text. Bind the created PR with the session's PR tools when available. Do not merge as a side effect.

Finish with the outcome, concrete evidence, and any remaining work. Do not invent unavailable tooling or silently skip a required check.
