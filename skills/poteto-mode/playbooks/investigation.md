# Investigation

Read [the runtime contract](../references/claude-runtime.md) first.

Define the question and relevant revision. Use how to trace the implementation and why for historical rationale. Inspect primary artifacts and run read-only observations when needed. Answer with sources, separate inference from observation, and leave the code unchanged unless the user separately requested a fix.

Finish with the outcome, concrete evidence, and any remaining work. Do not invent unavailable tooling or silently skip a required check.
